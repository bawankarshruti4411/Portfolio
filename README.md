# Shruti Bawankar — Data Analytics Portfolio

A personal data analytics portfolio built with **React (Next.js)**, **vanilla CSS + CSS Modules**, **semantic HTML5 (via JSX)**, and **JSON** configuration. No Tailwind, no Framer Motion — every animation is hand-written CSS so the project stays dependency-light and fully editable.

## Tech stack mapping

| Requirement | Where it lives |
|---|---|
| JavaScript / React / JSX | `components/*.jsx`, `pages/index.js`, `pages/_app.js`, `pages/_document.js` |
| Global CSS | `styles/globals.css` |
| Component CSS Modules | `components/*.module.css` (one per component) |
| Semantic HTML5 | Generated by JSX (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`, etc.) |
| JSON metadata/config | `package.json`, `jsconfig.json`, `.eslintrc.json` |
| Editable content | `data/siteData.js` — **edit this one file** to change all text/links |

## How to run it locally

1. Install [Node.js](https://nodejs.org) 18.17 or newer.
2. Unzip the project and open a terminal in the folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the dev server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:3000` in your browser.

## How to edit content

Open **`data/siteData.js`**. Every name, headline, project, skill, and FAQ answer on the site comes from this one file — change the text there and it updates everywhere it's used, with no need to touch any component.

To change colors, fonts, or spacing, edit the CSS variables at the top of **`styles/globals.css`** under `:root`.

## Design notes

- **Palette:** background `#080808`, surface cards `#111111`, neon lime accent `#C8F04E`.
- **Background:** a diagonal repeating-line grid plus a radial neon glow rising from the bottom of the page (see `.appShell` in `globals.css`).
- **Fonts:** Syne for display/headings, Inter for body text, JetBrains Mono for labels and data-style text.
- **Signature element:** an animated "data pulse" line (an SVG polyline that draws itself like a live readout) along the bottom of the Hero section — a nod to the data-analytics subject matter rather than a generic decorative flourish.
- All motion (pulsing badge, rotating star, marquee tickers, accordion spring-style easing, card tilt) is done with plain CSS animations/transitions and a small amount of mouse-tracking JS — no animation library required.

## Deploying

This is a standard Next.js app, so it deploys as-is to [Vercel](https://vercel.com), Netlify, or any Node hosting provider. Run `npm run build` then `npm run start` for a production build.
